 1) Scenario & requirements
You are building the API of Book&Ride, a bike rental service next to a bookstore café.
•	📚 Books: list, search, create, update and delete books (title, author, stock).
•	🚲 Rentals: start and stop a bike rental; price = €0.25 per started minute, capped at €12.
•	👤 Users: no login today. The user id is sent in an X-User-Id header (default 1). Real authentication moves to the gateway in Unit 04.
At the end of this lab, you will be able to:
•	Explain the trade-offs between a monolith and microservices and justify a choice in an ADR.
•	Run an API and a PostgreSQL database together with Docker Compose.
•	Structure a monolith into modules (routers) that share one codebase and one database.
•	Implement business logic (pricing) and protect it with unit tests.

Checkpoint 1 — Decide: monolith or microservices? (10 min)
Before writing code, architects record important decisions in an ADR (Architecture Decision Record): a short text file that explains what was decided and why. Use this table to decide for Book&Ride:
Question	Points to a monolith if…	Points to microservices if…
Team size?	One small team (2–5 people)	Several teams, each owning a part
Expected traffic?	Low, similar for all features	Very different per feature (e.g. rentals ×100)
Change frequency?	Everything changes together	Parts change and ship at different speeds
Data?	Shared data, strong consistency needed	Data can be split; eventual consistency is OK
Time to market?	Need a working product fast	Long-term platform, budget for DevOps

flange


 Line	Why
image: postgres:16-alpine	Official PostgreSQL image, small "alpine" variant.
volumes: dbdata:…	Data is stored in a named volume, so it survives docker compose down.
healthcheck: pg_isready	Docker knows when PostgreSQL is really ready to accept connections.
depends_on … service_healthy	The API only starts after the database is healthy.
ports: "8080:8080"	Publishes the API on your machine: http://localhost:8080. The database port is not published.

import os
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, sessionmaker
 
# PostgreSQL in Docker, SQLite file as a fallback for quick local tests
DATABASE_URL = os.getenv("DATABASE_URL", "sqlite:///./dev.db")
 
connect_args = {"check_same_thread": False} if DATABASE_URL.startswith("sqlite") else {}
engine = create_engine(DATABASE_URL, pool_pre_ping=True, connect_args=connect_args)
SessionLocal = sessionmaker(bind=engine, autoflush=False)
 
 
class Base(DeclarativeBase):
    pass
 
 
def get_db():
    """FastAPI dependency: one database session per request."""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

from datetime import datetime
from pydantic import BaseModel, ConfigDict, Field
 
 
class BookIn(BaseModel):
    title: str = Field(min_length=1, max_length=200)
    author: str = Field(min_length=1, max_length=120)
    stock: int = Field(default=0, ge=0)
 
 
class BookUpdate(BaseModel):          # every field optional: send only what changes
    title: str | None = Field(default=None, min_length=1, max_length=200)
    author: str | None = Field(default=None, min_length=1, max_length=120)
    stock: int | None = Field(default=None, ge=0)
 
 
class BookOut(BookIn):
    model_config = ConfigDict(from_attributes=True)   # read from SQLAlchemy objects
    id: int
flange
Schema	Used for
BookIn	The body of POST /books (all fields validated).
BookUpdate	The body of PUT /books/{id}: every field optional, send only what changes.
BookOut	What the API returns (adds the id; from_attributes reads SQLAlchemy objects).

PRICE_PER_MINUTE = 0.25   # €
DAILY_CAP = 12.0          # €
 
 
def calculate_price(minutes: int) -> float:
    """€0.25 per started minute, never more than €12."""
    if minutes < 0:
        raise ValueError("minutes must be >= 0")
    base = minutes * PRICE_PER_MINUTE
    return round(min(base, DAILY_CAP), 2)

4. The router (given: read it and make sure you understand each line):
flange  API/APP/ROUTERS/RENTALS.PY
import math
from datetime import datetime, timezone
 
from fastapi import APIRouter, Depends, Header, HTTPException, status
from sqlalchemy import select
from sqlalchemy.orm import Session
 
from ..db import get_db
from ..models import Rental
from ..pricing import calculate_price
from ..schemas import RentalStart, RentalStop
 
router = APIRouter(prefix="/rentals", tags=["rentals"])
 
 
@router.post("/start", status_code=status.HTTP_201_CREATED)
def start_rental(payload: RentalStart, db: Session = Depends(get_db),
                 x_user_id: int = Header(default=1)):
    # a bike cannot be rented twice at the same time
    busy = db.scalar(select(Rental).where(Rental.bike_id == payload.bike_id,
                                          Rental.stopped_at.is_(None)))
    if busy:
        raise HTTPException(status_code=409, detail=f"{payload.bike_id} is already rented")
    rental = Rental(user_id=x_user_id, bike_id=payload.bike_id,
                    started_at=datetime.now(timezone.utc))
    db.add(rental)
    db.commit()
    db.refresh(rental)
    return {"rental_id": rental.id, "bike_id": rental.bike_id,
            "started_at": rental.started_at.isoformat()}
 
 
@router.post("/stop")
def stop_rental(payload: RentalStop, db: Session = Depends(get_db)):
    rental = db.get(Rental, payload.rental_id)
    if rental is None:
        raise HTTPException(status_code=404, detail="Rental not found")
    if rental.stopped_at is not None:
        raise HTTPException(status_code=409, detail="Rental already stopped")
    now = datetime.now(timezone.utc)
    started = rental.started_at
    if started.tzinfo is None:                 # SQLite drops the timezone
        started = started.replace(tzinfo=timezone.utc)
    # every started minute counts
    minutes = max(1, math.ceil((now - started).total_seconds() / 60))
    rental.stopped_at = now
    rental.total_minutes = minutes
    rental.price_eur = calculate_price(minutes)
    db.commit()
    return {"rental_id": rental.id, "duration_min": minutes, "price_eur": rental.price_eur}
 
 
@router.get("")
def list_rentals(db: Session = Depends(get_db)):
    rentals = db.scalars(select(Rental).order_by(Rental.id)).all()
    return [{"rental_id": r.id, "user_id": r.user_id, "bike_id": r.bike_id,
             "started_at": r.started_at, "stopped_at": r.stopped_at,
             "price_eur": r.price_eur} for r in rentals]

flange
Rule in the code	Why
409 if the bike is already rented	A bike cannot be in two rentals at the same time.
math.ceil(seconds / 60), at least 1	Every started minute is paid: 61 seconds = 2 minutes.
datetime.now(timezone.utc)	Always store times in UTC; convert only for display.
X-User-Id header (default 1)	Temporary: in Unit 04 the gateway will set this header after checking an API key.
