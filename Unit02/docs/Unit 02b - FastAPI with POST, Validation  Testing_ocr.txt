* DB is a simple Python list. It lives in memory, so it is emptied every time the server restarts
(including with - - re1oad!). A real project would use a database (SQLite, PostgreSQL, MongoDB...).

* pagination is a dependency: a reusable function whose parameters (limit, offset) are read from
the query string and validated. Any route can use it with Depends(pagination).

* log creation will run as a background task: after the response has been sent, so the client does
not wait for it.

4) Lightweight tests (pytest + httpx)

Testing by hand with curl is fine once, but slow and easy to forget. Automated tests check your whole API

in one command, every time you change something.

Create test_app.py (in the same folder as main. py):

À TEST_APP.PY

import pytest
from httpx import AsyncClient, ASGITransport
from main import app, DB

@pytest. fixture (autouse=True)
def clear_db():
DB.clear() # every test starts with an empty "database"

@pytest.mark.asyncio
async def test_create_and_get_item():
transport = ASGITransport(app=app)

async with AsyncClient(transport-transport, base url-"http://test") as ac:

# create

payload - (
"name": "Banana",
"price": 1.2,
"tags": ["fruit"],

"rating": 4.0
}
r = await ac.post("/items", json=payload)
assert r.status code == 201

data = r.json()
assert data["id"] == 1
assert data["name"] == "Banana"

# get

r2 = await ac.get("/items/1")

assert r2.status_code == 208

assert r2.json()["name"] == "Banana"

@pytest.mark.asyncio
async def test_validation_error():
transport = ASGITransport (app=app)

async with AsyncClient(transport-transport, base url-"http://test") as ac:

r = await ac.post("/items", json={"name": "A", "price": 10})
assert r.status_code == 422

À Watch out

Older tutorials write AsyncClient(app=app, ...). This argument was removed in httpx 0.28: you now pass
the app through ASGITransport(app=app), as above.

The clear_db fixture empties the in-memory list before each test. Without it, the order of the tests would
change the ids, and data["id"] == 1 could fail.

@pytest. fixture (autouse=True) Code that runs automatically before every test.
@pytest.mark.asyncio Tells pytest (with pytest-asyncio) to run this async test.

Sends requests directly to the app in memory: no server needs

ASGITransport(app=app} to be running

If the condition is false, the test fails and pytest shows the

assert
values.
